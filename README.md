# 旅行日记·片语｜小影AI成片功能提案

这是一个非官方功能概念，拟议入口为“创作页 → AI成片 → 旅行日记”。它承接小影已有模板、素材与编辑能力，新增模板初稿后的个人表达修正。这里的导航是方案设计，不代表当前小影App已采用这一布局。

## 推荐演示路径

1. 在概念创作页选择“顺叙日记”，用6段示例进入。也可以导入3–8段自己的照片或视频。
2. 补充一句真实感受，选择故事、语气和时长，再生成主题初稿。“海边开场”会改变实际顺序、非均分时长和字幕样式。
3. 选择第6段，改一句话，对比模板原句后保存；满意的段落可以锁定。也能让某段不加字幕，或排序、撤销。
4. 修改封面标题，选择是否开启演示配乐。标题、当前字幕、顺序与配乐设置都作用于真实导出。
5. 在“原型说明”中模拟一次生成中断，直接用原输入重试。
6. 先生成视频，再点击“下载已生成视频”。浏览器发起下载不等于文件已经保存或内容已发布。
7. 完成后沿用风格再做一条，上一稿留在本机最近草稿里；“继续精剪”只展示拟议交接清单，不调用真实小影App。

## 评审后修复

- 素材选择、主题、文字或时长变化后，旧初稿需更新；不会继续导出取消的素材。
- 不再要求补充文字与默认文本完全相同：关键词规则对应示例素材，未匹配句子保留为待确认，不按索引硬塞。
- 重新导入保留补充文字；整组素材替换使用新的任务身份，避免混用示例与自带素材分母。
- 锁定句在对应素材仍存在时保留；撤销同步恢复编排相关设置。
- 本机归档失败时保留当前草稿；配乐准备期间作品变化会中止旧导出。

## 实现边界

没有在线AI模型、后台或真实小影账号集成。示例注释不是模型识别结果。自带素材只在浏览器本地处理，不识别画面或语音；刷新后需重新选择，补充文字与风格保留。

示例图片由内置imagegen生成，以轻微推拉组成片段。配乐由本Demo的原创代码合成，不调用小影音乐库，不使用热门歌曲。当前不合成自带视频原音或旁白。WebM导出需要Canvas、WebAudio和MediaRecorder支持，推荐Chrome/Edge；合成时保持页面在前台，支持取消。

本机草稿与最近版本使用localStorage，最多保留5份归档。编排JSON只保存顺序、字幕与设置，不含媒体，不支持在此Demo内重新导入。

## 反馈与数据

“这版能继续用吗”记录用户明确反馈。操作事件只保存在本机最近300条，不上传；不记录用户文字、文件名或媒体。原型说明可以查看最近8条并导出JSON。模拟编排/改写/失败标记为is_simulated；文件生成与下载请求分开记录，不记录虚构的保存成功或发布成功。

后续主指标为“可接受初稿确认率”：窗口内末次反馈为可继续剪的去重任务数 / 全部有效开始任务数。重试不增加分母，示例与自带素材分开，未反馈与放弃单独报告。当前没有真实转化、留存、增长或模型效果结论。

## 图片生成记录

工具：内置 imagegen。六张图片均为本次生成；原图保留，网页版本仅进行格式压缩。

共同提示词：竖屏9:16、真实手机旅行随拍、自然阴天光线、低饱和色、没有文字/标志/水印，不做拼贴。

- `tram.webp`：从海边城市电车内部看向阴天的沿海街道，绿色座椅与带雨滴的车窗。
- `coffee.webp`：米色外套的手握着无标志白色外带咖啡杯，咖啡馆窗外是灰蓝海边。
- `sea.webp`：阴天灰蓝海面、木栅栏与沙丘草，不出现日落或阳光束。
- `dog.webp`：奶油色小狗背影沿湿沙滩跑动，阴天，无人物面部。
- `sand.webp`：第一人称俯拍奶油色运动鞋和卷起的深色裤脚，湿沙与薄海浪。
- `dusk.webp`：阴天蓝调时刻的安静海滩、反光湿沙、远处海滨路灯，不出现太阳。

完整提示词结构：photorealistic-natural / vertical sample media / candid handheld phone travel diary / realistic textures / quiet muted colors / no cinematic grading / clear focal point and room for captions at bottom。
